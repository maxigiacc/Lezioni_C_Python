Python come linguaggio orientato agli oggetti: storia, concetti e curiosità

Parte 1: Un po’ di storia
Le origini della programmazione a oggetti
La programmazione orientata agli oggetti nasce negli anni ‘60 con il linguaggio Simula, sviluppato da Ole-Johan Dahl e Kristen Nygaard in Norvegia. Era pensato per la simulazione di sistemi complessi, ed è qui che nascono concetti come "classe" e "oggetto".

Negli anni '80, arriva Smalltalk, considerato il primo vero linguaggio completamente orientato agli oggetti. Tutto in Smalltalk è un oggetto, persino i numeri.

Poi arriva C++, che porta l’OOP nel mondo dei linguaggi compilati e ad alte prestazioni. E infine, tra la fine degli anni ’80 e l’inizio dei ‘90, un simpatico olandese di nome Guido van Rossum inizia a sviluppare Python.

1. Classi e Oggetti
Nel mondo reale, un “oggetto” può essere una persona, un’auto, una pizza. In Python, un oggetto è un’istanza di una classe, che è una sorta di stampo.

Che cos’è una classe?
Una classe è un modello, una sorta di prototipo che descrive le caratteristiche e i comportamenti che gli oggetti creati da essa avranno.

Immagina una classe come un progetto architettonico per una casa: nel progetto c’è scritto quante stanze ha, dove sono le porte, com’è fatta la cucina... ma finché non costruisci una casa vera e propria, non ci puoi abitare.

In Python, una classe si definisce con la parola chiave class:

class Cane:
    def __init__(self, nome, razza):
        self.nome = nome
        self.razza = razza

    def abbaia(self):
        print(f"{self.nome} dice: Bau!")
📌 __init__ – il costruttore
Il metodo __init__ viene eseguito automaticamente quando crei un oggetto. Serve per inizializzare l’oggetto, cioè assegnare i valori iniziali agli attributi (variabili) dell’oggetto.

🔹 Che cos’è un oggetto?
Un oggetto è una istanza (copia concreta) di una classe. È qualcosa che esiste in memoria, con i suoi dati e comportamenti.

Continuando con l’analogia della casa: la classe è il progetto, l’oggetto è la casa vera e propria costruita in mattoni e cemento.

Creare un oggetto si chiama istanza della classe:

fido = Cane("Fido", "Labrador")
fido.abbaia()  # Output: Fido dice: Bau!
In questo esempio:

Cane è la classe.

fido è un oggetto (o istanza) della classe Cane.

Ha attributi (nome, razza) e metodi (abbaia).

🔹 Cosa contiene una classe?
Una classe può contenere:

Attributi (dati, proprietà)

Variabili associate all’oggetto

Es. nome, età, peso

Metodi (funzioni)

Azioni che l’oggetto può compiere

Es. abbaia(), cammina(), mangia()

Esempio:
class Auto:
    def __init__(self, marca, modello):
        self.marca = marca
        self.modello = modello

    def descrizione(self):
        print(f"Auto: {self.marca} {self.modello}")
Creiamo due oggetti:
a1 = Auto("Fiat", "Panda")
a2 = Auto("Tesla", "Model S")

a1.descrizione()  # Fiat Panda
a2.descrizione()  # Tesla Model S
Ogni oggetto ha i suoi dati, anche se vengono dallo stesso modello.

🔹 Il concetto di self
In ogni metodo di una classe, il primo parametro è sempre self. Rappresenta l’istanza corrente dell’oggetto. Python lo passa automaticamente quando chiami un metodo.

Ad esempio:
def abbaia(self):
    print(f"{self.nome} dice: Bau!")
self.nome significa “l’attributo nome dell’oggetto corrente”.

🔹 Creare più oggetti
Una classe è come uno stampo: puoi creare tantissimi oggetti diversi, ognuno con le sue caratteristiche.

cani = [
    Cane("Fido", "Labrador"),
    Cane("Luna", "Pastore Tedesco"),
    Cane("Rex", "Bulldog")
]

for c in cani:
    c.abbaia()

Concetto	    Descrizione breve	    Esempio
Classe	        Il progetto/definizione	class Cane:
Oggetto	    Un’istanza concreta della classe	fido = Cane("Fido", ...)
Attributo	Variabile contenuta nell’oggetto	self.nome
Metodo	    Funzione che l’oggetto può eseguire	def abbaia(self):
self	    Riferimento all’oggetto stesso	self.nome = nome



2. Incapsulamento
L’incapsulamento è il principio secondo cui i dati interni di un oggetto sono protetti e possono essere modificati solo attraverso metodi controllati.

In Python, non esiste un vero "private" come in Java o C++, ma c'è una convenzione:

class ContoBancario:
    def __init__(self, saldo_iniziale):
        self.__saldo = saldo_iniziale

    def deposita(self, importo):
        self.__saldo += importo

    def mostra_saldo(self):
        return self.__saldo
Quella doppia underscore (__) non rende davvero la variabile privata, ma la "mangia" internamente (name mangling). È più un “non toccarlo se non sai cosa fai” che un vero blocco.

3. Ereditarietà
L’ereditarietà è la capacità di una classe di riutilizzare il codice di un’altra classe. In Python si fa con una sintassi semplice:

class Animale:
    def parla(self):
        print("L’animale emette un suono.")

class Cane(Animale):
    def parla(self):
        print("Bau!")

fido = Cane()
fido.parla()
Python supporta anche l’ereditarietà multipla, che può essere potente… o pericolosa.

Aneddoto: il famoso problema del "diamond problem", risolto da Python con un algoritmo chiamato C3 Linearization. (Sì, esiste anche un algoritmo per stabilire l’ordine delle classi in eredità multipla!)

4. Polimorfismo
Il polimorfismo consente di usare un'interfaccia comune per oggetti di classi diverse. In Python questo è naturale, grazie al duck typing: “se cammina come un’anatra e fa qua qua come un’anatra…”

class Gatto:
    def parla(self):
        print("Miao")

class Mucca:
    def parla(self):
        print("Muu")

def fai_parlare(animale):
    animale.parla()

fai_parlare(Gatto())
fai_parlare(Mucca())
Non serve implementare un’interfaccia, come in Java. Basta che l’oggetto abbia il metodo richiesto.

Parte 3: Python e l’OOP nel dettaglio
Tutto è un oggetto
In Python tutto è un oggetto. Anche int, list, functions, perfino le classi stesse sono oggetti:

print(isinstance(42, object))       # True
print(isinstance(print, object))    # True
print(isinstance(Pizza, object))    # True

Parte 4: Curiosità, vantaggi e uso nel mondo reale
Curiosità
Guido van Rossum è stato il “Benevolent Dictator For Life” di Python fino al 2018. Ha lasciato volontariamente il ruolo per godersi un po’ di meritata pace… salvo poi essere assunto da Microsoft nel 2020!

Il nome Python è un omaggio ai Monty Python’s Flying Circus, e molti esempi ufficiali del linguaggio contengono riferimenti umoristici (spam, eggs, knights who say "ni").

Vantaggi dell’OOP in Python
Modularità: puoi dividere il codice in oggetti facilmente riutilizzabili.

Manutenibilità: il codice OOP è più facile da aggiornare.

Espandibilità: aggiungere funzionalità è più semplice.

Framework e librerie: Django, Flask, PyQt, e moltissimi altri usano OOP in modo estensivo.

Parte 5: Conclusione e consigli pratici
Python è un linguaggio versatile, elegante e potente per la programmazione orientata agli oggetti. Che tu stia sviluppando un gestionale, un videogioco o un’app web, capire l’OOP in Python ti dà un vantaggio enorme.

Consigli finali:
Usa classi solo quando servono. Python permette uno stile flessibile: non esagerare con l’OOP se non porta vantaggi reali.

Scrivi codice leggibile. Segui il principio zen di Python: “Readability counts”.

Sperimenta. Gioca con l’ereditarietà, crea le tue classi, sovrascrivi i dunder methods. Imparerai molto.
